# Hey, I'm Laween

I'm a software developer and Computer Science Ph.D. student at North Dakota State University.

I like figuring out how things work, finding what could be better, and making it better. Most of the things I build start because something catches my attention, annoys me, or makes me wonder how far I can take an idea.

I enjoy the part between getting something to work and getting it to work right, figuring out why something fails, cleaning up rough edges, and changing things until the result actually feels good to use.

I studied civil engineering before computer science, so maybe I've always just liked building things.

## Featured Projects

### [TinyNetUse](https://github.com/laween-alsulaivany/TinyNetUse)

A small Windows utility for monitoring download and upload speeds in a movable desktop overlay, with an optional history graph and configurable appearance.

### [Course Headcounts](https://github.com/laween-alsulaivany/headcounts-web)

A web app for searching and analyzing MSUM course enrollment data. I worked on the front-end redesign and handled its Docker deployment, infrastructure, and data pipeline.

### [Dark Souls III Reinforcement Learning](https://github.com/laween-alsulaivany/Beating-Dark-Souls-III-Ludex-Gundyr-with-Reinforcement-Learning)

A PPO training environment built around the Iudex Gundyr boss fight. It reads game state directly from memory and automates actions, training, and episode resets.

### [LA UI](https://github.com/laween-alsulaivany/LA_UI)

My personal CSS style guide for application interfaces. I use it to keep the layouts, components, and small design decisions consistent across projects.

### [ReqWatcher](https://github.com/laween-alsulaivany/reqwatcher)

A small command-line tool that keeps track of packages installed with pip and records them in a requirements file.
